# Shared example standard

These examples follow the [v0.3.35 shared standard](https://github.com/Query-farm/vgi-example-notebooks/blob/v0.3.35/docs/standard.md) and [coverage evidence format](https://github.com/Query-farm/vgi-example-notebooks/blob/v0.3.35/docs/coverage.md).

SVG is the default figure format. The document preview remains a worker-rendered raster embedded inside its SVG figure. Notebook setup pins the shared base package; local execution uses its locked runner extra. Immutable companions are hash-verified. Worker source and root dependencies are unchanged, so existing green source CI is reused.
